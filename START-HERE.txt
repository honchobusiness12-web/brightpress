BRIGHTPRESS V2 — SUPER SIMPLE SETUP

1) SUPABASE
   - Create a Supabase project.
   - Open SQL Editor.
   - Paste ALL of supabase.sql.
   - Click Run.

2) GOOGLE LOGIN
   - Supabase → Authentication → Providers → Google → Enable.
   - Create Google OAuth credentials in Google Cloud.
   - Copy the callback URL Supabase gives you into Google's authorized redirect URIs.
   - In Supabase → Authentication → URL Configuration, add:
       http://localhost:3000
       http://localhost:3000/auth/callback
     and later your real domain + /auth/callback.

3) ENVIRONMENT
   - Copy .env.example to .env.local
   - Fill in:
       NEXT_PUBLIC_SUPABASE_URL
       NEXT_PUBLIC_SUPABASE_ANON_KEY

4) RUN
   Open a terminal in this folder:
       npm install
       npm run dev
   Then open:
       http://localhost:3000

5) MAKE YOURSELF ADMIN
   - Sign in with Google on the site.
   - In Supabase → Table Editor → profiles, find yourself.
   - Change role from user to admin.

6) STAFF LOGIN
   Go to:
       http://localhost:3000/admin/login
   Admin dashboard:
       http://localhost:3000/admin

7) GITHUB + VERCEL
   - Push this folder to GitHub.
   - Import the repo into Vercel.
   - Add the same two NEXT_PUBLIC_* environment variables in Vercel.
   - Add your Vercel URL and /auth/callback to Supabase redirect URLs.

IMPORTANT
- Never upload .env.local.
- Never put a Supabase service-role key in the browser.
- If Google login gives a redirect error, the redirect URL in Supabase/Google does not match your current site URL.
